# Batch 3 — 300 game pages

This cumulative development package preserves the previous Quick-Launch project and adds `batch3-games/` with 300 separate HTML game pages plus `batch3-games.html` as a catalogue.

## Honest status
- 300 separate game pages generated, each with a unique title, page, goal text, timer/level settings, and rule twist.
- Pages use 30 shared gameplay engines with per-page variations. This is **not yet proof of 300 entirely unique core mechanics**, so do not market it as having zero repeated mechanics.
- Automated checks cover file count, HTML page references, and inline JavaScript syntax. Manual browser gameplay testing is still required.
- The previous website and its original files remain unchanged online; this is only a downloadable package.

## Open
Open `batch3-games.html` on the hosted site or serve the folder from a local web server for best results.
