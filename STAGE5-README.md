# Stage 5 — 500-game catalog
Open `stage5-games.html` to search and filter all 500 entries. `stage5-games.json` is the structured catalog.

The catalog contains the first 150 Stage 4 entries plus 350 Stage 5 expansion entries. All 500 titles are unique. This is a catalog milestone, not a claim that all games are implemented or similarity-tested. Each game still needs an individual playable implementation, mechanic review, and real difficulty scaling through 2048×.

The previous Stage 3 leaderboard remains a configuration scaffold, not a live connected service.
