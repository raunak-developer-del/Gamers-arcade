# Gamers’ Arcade — Part 5: 500 Games

This package expands the catalogue to **500 unique game titles**, numbered 1–500. It adds 100 entries (401–500) and updates the large homepage heading and all visible catalogue counters to 500.

## Included files
- `index.html`: responsive homepage with the correct **500 GAMES** heading.
- `games-data.js`: 500 unique game catalogue entries.
- `app.js` and `styles.css`: search, category filters, and catalogue display.
- `pacman.html`: original Pac-Man file carried forward unchanged.
- `candy-crush.html`: standalone match-3 game.
- `play.html` and `microgames.js`: game launcher and lightweight browser-game mechanics/prototypes.

## Update your GitHub Pages website
1. Download and extract this ZIP.
2. Open your existing repository and choose **Add file → Upload files**.
3. Upload all nine files to the same published folder as your current `index.html`, replacing matching project files.
4. Commit the changes, then refresh your website with **Ctrl + Shift + R**.
5. Keep the repository and GitHub Pages settings. Back up unrelated files first. If `engine.js` is already in your repository, leave it unless you have confirmed nothing uses it.

## Important note
The catalogue has 500 unique titles, but not all 500 are fully bespoke, polished games. Many entries use lightweight shared prototype mechanics. The homepage catalogue should list all 500 entries; this does not mean every entry has a completely different game engine.
