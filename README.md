# Gamers' Arcade — Part 4: 400 Games

This expanded website package contains the previous catalogue plus 100 new entries (games 301–400), for 400 unique game titles in total.

## Included files
- `index.html`: responsive library updated for 400 game entries.
- `games-data.js`: 400 unique catalogue entries, including new games 301–400.
- `app.js` and `styles.css`: library filtering, search, and styling.
- `pacman.html`: original Pac-Man HTML carried forward unchanged from the previous package.
- `candy-crush.html`: standalone match-3 game.
- `play.html` and `microgames.js`: launcher and lightweight browser-game mechanics/prototypes.

## Upload to GitHub Pages
1. Download and extract this ZIP.
2. Open your existing GitHub repository.
3. Select **Add file → Upload files**.
4. Upload the nine files inside this folder to the same published folder as your current `index.html`, replacing the matching project files.
5. Commit the changes. Keep your repository and GitHub Pages settings. Back up unrelated files first. If your repository has an extra `engine.js`, leave it in place unless you have confirmed nothing uses it.

## Build note
The catalogue contains 400 distinct titles. Some entries use lightweight generic challenges/prototypes rather than fully bespoke mechanics and should be expanded and tested further. Pac-Man and Candy Cascade remain included.
