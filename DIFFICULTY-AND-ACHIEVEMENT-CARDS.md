# Difficulty & Achievement Cards — Batch 4 Update

- Every Batch 4 game now has a difficulty selector from ×1 through ×2048.
- Higher tiers raise target requirements, adjust variant intensity and tighten the time limit (with a safety floor).
- Winning a game creates a neon achievement-card preview.
- **Download Achievement PNG** exports a shareable 1200×675 PNG card with game title, score, multiplier, XP, date, and game number.
- XP tiers use 5× scaling: ×1 = 50, ×2 = 250, ×4 = 1,250, ×8 = 6,250, ×16 = 31,250, ×32 = 156,250, and so on.
- XP is accumulated in local browser storage. This is not a secure/global leaderboard; a real international leaderboard needs a server/backend.
- Existing homepage, game pages, original assets, and neon theme are retained.
- Note: this improves difficulty progression and achievement sharing, but does not claim that the 500 pages represent 500 different core mechanics.
