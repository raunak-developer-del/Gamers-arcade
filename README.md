# Gamers' Arcade — 500 Individual Mini-Game Pages

## Open it
Open `index.html` in a browser, or upload the contents of this folder to a static host such as GitHub Pages.

## What is included
- 500 separate playable HTML game pages.
- Searchable/filterable neon-themed library.
- Touch/pointer and keyboard input in supported game types.
- Each page has its own title, tuning, target, speed, difficulty, palette and seed.
- No server or external library required.

## Important honesty note
This is a 500-page mini-game prototype, not 500 professionally hand-designed, fully distinct games. The pages use a collection of reusable gameplay families with different configurations. Some game families are simpler prototypes and should be play-tested and improved before public release. The Vector-Physics Pac-Man from your existing website is not included here, so keep your current site backup and merge carefully rather than deleting it.
