- Adds 10 standalone game pages under `games/unique-batch-02/`.
- Adds `part2-games.html` as the Part 2 catalogue.

## Verification limits
All pages are standalone HTML with embedded JavaScript. Syntax and archive checks are run during packaging; these are not a substitute for interactive browser playtesting. Chess is not included in this batch because a full legal-move/check/checkmate implementation requires additional work. The live GitHub Pages site has not been modified.
